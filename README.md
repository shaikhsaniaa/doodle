# doodle 🎨

An interactive HTML5 Canvas app for freehand doodling and drawing customizable geometric shapes. Features an adjustable brush, custom color picker, shape fills, and a one-click button to download your artwork as an image.

---

## 🚀 Features

* **Freehand Drawing & Erasing:** Draw smooth strokes or erase mistakes with an adjustable tool.
* **Geometric Shapes:** Easily render **Rectangles**, **Circles**, and **Triangles**.
* **Fill & Outline Toggle:** Switch between hollow outline shapes and solid filled shapes.
* **Custom Palette:** Choose preset colors or pick any custom shade using the color picker.
* **Adjustable Brush Size:** Control brush and eraser thickness with a smooth range slider.
* **Clear & Save:** Reset your drawing area instantly or export your artwork directly as a `.jpg` image.

---

## 🛠️ Tech Stack

* **HTML5** (Canvas API)
* **CSS3** (Flexbox, Google Fonts)
* **JavaScript** (Vanilla JS)
